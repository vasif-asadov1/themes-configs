# Ubuntu Aubergine Rose Light Advanced

A distinctly aubergine-tinted **light** theme—not a white editor. Warm mauve editor, dusty rose sidebar, plum UI chrome, and dark readable syntax.

Install the VSIX with `code --install-extension ubuntu-aubergine-rose-light-2.1.0.vsix --force`, reload VS Code, and select **Ubuntu Aubergine Rose Light Advanced**.
