# Ubuntu Aubergine Red Light Advanced 2.2.0

A warm red-based, non-white light VS Code theme derived from Ubuntu Aubergine Rose Light 2.1.0. Maintains 351 workbench color entries, 177 TextMate token rules, and semantic highlighting.

## Installation

Package using `npx --yes @vscode/vsce package --allow-missing-repository --out /tmp/ubuntu-aubergine-red-light-2.2.0.vsix`, then install with `code --install-extension /tmp/ubuntu-aubergine-red-light-2.2.0.vsix --force`.
